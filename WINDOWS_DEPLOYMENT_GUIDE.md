# Windows Deployment Guide: Node.js + Vite + TypeScript

This guide provides two complete solutions for converting your Vite + Node.js web project into a permanent Windows 10 application.

---

## OPTION 1: Local Website (Background Windows Service)

This option runs your Node.js server as a native Windows Service. It will start automatically when the computer boots, run silently in the background, and be accessible via `http://localhost:3000` in any browser.

### 1. Required NPM Packages
Install `node-windows` to create the service, and a build tool like `esbuild` or `tsc` to compile your `server.ts`.

```bash
npm install --save node-windows
npm install --save-dev esbuild
```

### 2. Modified Folder Structure
Add a script to install the service:
```text
├── src/
├── dist/               # (Generated by Vite)
├── dist-server/        # (Generated compiled server)
├── server.ts
├── install-service.js  # NEW: Script to register the Windows service
├── uninstall-service.js# NEW: Script to remove the service
└── package.json
```

### 3. Build the Application
You need to build both the frontend (Vite) and the backend (`server.ts`). Add these scripts to your `package.json`:

```json
"scripts": {
  "build:frontend": "vite build",
  "build:server": "esbuild server.ts --platform=node --target=node16 --outfile=dist-server/server.js --bundle --external:express",
  "build": "npm run build:frontend && npm run build:server"
}
```

### 4. Configuration Files

**`install-service.js`**
```javascript
const Service = require('node-windows').Service;
const path = require('path');

// Create a new service object
const svc = new Service({
  name: 'My Web Application',
  description: 'Local web server running on port 3000.',
  script: path.join(__dirname, 'dist-server', 'server.js'),
  nodeOptions: [
    '--harmony',
    '--max_old_space_size=4096'
  ]
});

// Listen for the "install" event, which indicates the process is available as a service.
svc.on('install', function() {
  console.log('Service installed successfully.');
  svc.start();
  console.log('Service started. Access it at http://localhost:3000');
});

svc.install();
```

**`uninstall-service.js`**
```javascript
const Service = require('node-windows').Service;
const path = require('path');

const svc = new Service({
  name: 'My Web Application',
  script: path.join(__dirname, 'dist-server', 'server.js')
});

svc.on('uninstall', function() {
  console.log('Uninstall complete.');
});

svc.uninstall();
```

### 5. Deployment Steps
1. Run `npm run build` to generate the production files.
2. Open an **Administrator** Command Prompt or PowerShell.
3. Navigate to your project folder.
4. Run `node install-service.js`.
5. The app is now permanently installed. It will survive reboots and run offline.

---

## OPTION 2: Windows Desktop Application (.EXE) via Electron

This option wraps your Node.js backend and Vite frontend into a standalone `.exe` installer using **Electron** and **Electron Builder**. It does **not** require Node.js to be installed on the target computer.

### 1. Required NPM Packages
```bash
npm install --save-dev electron electron-builder concurrently wait-on esbuild
```

### 2. Modified Folder Structure
```text
├── src/
├── electron/
│   └── main.js         # NEW: Electron entry point
├── dist/               # (Generated by Vite)
├── dist-server/        # (Generated compiled server)
├── server.ts
└── package.json
```

### 3. Configuration Files

**`electron/main.js`**
This script starts your Express server in the background, waits for it to be ready, and then opens the Electron window.

```javascript
const { app, BrowserWindow } = require('electron');
const path = require('path');
const { fork } = require('child_process');

let mainWindow;
let serverProcess;

function createWindow() {
  mainWindow = new BrowserWindow({
    width: 1280,
    height: 800,
    autoHideMenuBar: true,
    webPreferences: {
      nodeIntegration: false,
      contextIsolation: true
    }
  });

  // Load the local server
  mainWindow.loadURL('http://localhost:3000');

  mainWindow.on('closed', function () {
    mainWindow = null;
  });
}

app.on('ready', () => {
  // 1. Start the Express server as a child process
  const serverPath = path.join(__dirname, '../dist-server/server.js');
  serverProcess = fork(serverPath, [], {
    env: { ...process.env, NODE_ENV: 'production', PORT: 3000 }
  });

  // 2. Give the server a moment to bind to the port, then open the window
  setTimeout(createWindow, 1000);
});

// Kill the server when the app closes
app.on('will-quit', () => {
  if (serverProcess) {
    serverProcess.kill();
  }
});

app.on('window-all-closed', function () {
  if (process.platform !== 'darwin') app.quit();
});
```

**`package.json` Updates**
You must add the `main` entry point, update your scripts, and add the `build` configuration for `electron-builder`.

```json
{
  "name": "my-desktop-app",
  "version": "1.0.0",
  "main": "electron/main.js",
  "scripts": {
    "dev": "vite",
    "build:frontend": "vite build",
    "build:server": "esbuild server.ts --platform=node --target=node16 --outfile=dist-server/server.js --bundle --external:express",
    "build": "npm run build:frontend && npm run build:server",
    "pack": "npm run build && electron-builder --dir",
    "dist": "npm run build && electron-builder --win"
  },
  "build": {
    "appId": "com.mycompany.myapp",
    "productName": "My Desktop App",
    "directories": {
      "output": "release"
    },
    "files": [
      "dist/**/*",
      "dist-server/**/*",
      "electron/**/*",
      "node_modules/**/*"
    ],
    "win": {
      "target": [
        {
          "target": "nsis",
          "arch": ["x64"]
        }
      ],
      "icon": "public/icon.ico"
    },
    "nsis": {
      "oneClick": false,
      "allowToChangeInstallationDirectory": true,
      "createDesktopShortcut": true,
      "createStartMenuShortcut": true
    }
  },
  "dependencies": {
    "express": "^4.18.2"
  }
}
```
*(Note: Ensure all backend dependencies like `express` are in `dependencies`, not `devDependencies`, so Electron Builder includes them).*

### 4. Build Commands & Packaging Method

To generate the final `.exe` installer:

1. **Build the project and generate the installer:**
   ```bash
   npm run dist
   ```
2. **Locate the Installer:**
   Once the command finishes, look inside the newly created `release/` folder. You will find a file named something like `My Desktop App Setup 1.0.0.exe`.

### 5. Installer Setup Details
The `"nsis"` block in the `package.json` configuration handles the installer setup automatically:
* `oneClick: false`: Gives the user a standard installation wizard (Next > Next > Install).
* `allowToChangeInstallationDirectory: true`: Lets the user choose where to install it (e.g., `C:\Program Files\My Desktop App`).
* `createDesktopShortcut: true`: Automatically places an icon on the Windows desktop.

When a user runs this `.exe`, it will install the application, bundle its own internal version of Node.js (via Electron), and run entirely offline without requiring the user to install any prerequisites!
